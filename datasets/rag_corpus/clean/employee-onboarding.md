# Employee Onboarding

New employees at Acme Corp start on a Monday. The first day begins with a virtual orientation at 9:00 am local time, led by the People team, followed by a welcome lunch with the new hire's team.

IT ships each new hire's laptop 5 business days before the start date. The laptop arrives enrolled in Fleetwise device management, and the Acme ID account is activated on the morning of the first day. Hardware security keys for multi-factor sign-in are handed out during orientation.

Every new employee is paired with an onboarding buddy from a different team for the first 90 days. Managers prepare a 30-60-90 day plan with clear goals for each stage and review it with the new hire during the first week.

Security awareness training and the code of conduct acknowledgment are completed within the first 7 days. Payroll and benefits enrollment is completed in PeopleHub within the first 30 days; employees who miss the window wait for the next open enrollment period.

The onboarding program ends with a 90-day check-in between the new hire, the manager and the People partner. Feedback from that check-in is used to improve the program each quarter.
